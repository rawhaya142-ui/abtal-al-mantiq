نشرها على GitHub Pages:
1) فك ضغط الملف.
2) ارفع الملفات index.html و manifest.json و sw.js و icon.svg إلى جذر المستودع.
3) افتح Settings > Pages.
4) اختر Deploy from a branch ثم main والمجلد /(root)، واضغط Save.
5) انتظر ظهور رابط الموقع وافتحه عبر HTTPS.
اللعبة تحفظ مجموع النقاط محليًا على جهاز اللاعب.
