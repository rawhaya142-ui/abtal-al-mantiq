أبطال المنطق - الصف العاشر

تشغيل سريع:
1. فكّي ضغط الملف.
2. افتحي index.html في المتصفح لتجربة اللعبة.

التثبيت كتطبيق PWA:
- التثبيت على الشاشة الرئيسية يحتاج نشر الملفات على استضافة HTTPS (مثل GitHub Pages أو Netlify).
- بعد النشر، افتحي رابط اللعبة في Chrome على الهاتف، ثم من القائمة اختاري «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».
- الخدمة دون اتصال تعمل بعد فتح الموقع مرة واحدة وتحميل ملفات التخزين المؤقت.

ملاحظة: بعض المتصفحات لا تعرض أيقونة SVG في قائمة التثبيت؛ يمكن استبدالها بأيقونات PNG 192x192 و512x512 عند النشر النهائي.
